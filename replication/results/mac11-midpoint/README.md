## Commands actually executed

From the Silo root:

```bash
python3 -B replication/midpoint/replay.py
# Bundled Python with ReportLab:
python3 -B replication/midpoint/make_results.py
```

The temporary compiler was downloaded from the official Tectonic 0.17.0
release. From `replication/midpoint/`:

```bash
/private/tmp/mac11-tex/tectonic --untrusted --keep-logs --keep-intermediates \
  --outdir ../../output/pdf project_milestone.tex
# Final build after page numbering and image-description edits:
/private/tmp/mac11-tex/tectonic --untrusted --only-cached --keep-logs \
  --keep-intermediates --outdir ../../output/pdf project_milestone.tex
```

Poppler rendered the final PDF at 110 dpi with a temporary writable fontconfig
cache. All five final images were inspected; no image-processing transform was
used to alter report content. PDF text was checked with `pypdf`.

```bash
python3 -B replication/midpoint/package.py \
  --masstree-archive /private/tmp/mac11-masstree-source.tar.gz
```

The dependency came from GitHub's `kohler/masstree-beta` tarball for pinned
`1150824e6a10a0384ba4bfed6b916ce62f96315f`. The package stores its source and
archive hash, source/evidence and the report overlay, without Git history or
compiled test executables. ZIP extraction/hash checks and the extracted replay
ran in a fresh temporary directory; that copy also rebuilt the TeX report.

## Retained failures and limitations

The first replay stopped at safe extraction's path-containment assertion:
macOS aliases `/var` to `/private/var`, so the resolved member path did not
compare equal to the unresolved temporary root. Resolving the root corrected
the check; the entire replay was rerun successfully.
[Attempt log](replay-attempt1.log).

The first TeX build stopped because acmart and `changes` both define `comment`.
The package's documented `commandnameprefix=ifneeded` option resolved the
collision. Full compilation then succeeded, followed by a cached final build.
[Compiler attempt](compile-attempt1.log) · [TeX attempt](tex-attempt1.log).
